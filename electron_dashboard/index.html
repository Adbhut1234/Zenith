Setup Guide

Acquire necessary credentials to activate your Zenith desktop assistant.

1. Google Gemini API (Neural Brain)
Open AI Studio

1. Visit Google AI Studio and sign in.
2. Click Create API Key.
3. Paste the generated key into the Google Gemini API Key field under Configurations.

2. LiveKit Cloud (Voice Telemetry)
Open LiveKit Cloud

1. Sign up on LiveKit Cloud and create a free project.
2. Navigate to Settings > Keys in your project dashboard.
3. Click Add New Key and copy the WebSocket URL, API Key, and Secret into Configurations.

3. Gmail SMTP App Password (Optional)
Google Security

1. Ensure 2-Step Verification is active on your Google account.
2. Search for App Passwords and create one named "Zenith".
3. Paste the 16-character token into the Configurations tab.
