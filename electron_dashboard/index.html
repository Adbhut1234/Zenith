Setup Protocols & API Guides

Acquiring essential credentials to activate Zenith's neural matrix.

1. Google Gemini API (Neural Brain)

1. Visit Google AI Studio and sign in with your Google Account.

2. Click Create API Key.

3. Copy the key and paste it into the Google Gemini API Key field in the Configurations tab.

2. LiveKit Cloud (Voice Telemetry)

1. Sign up at LiveKit Cloud.

2. Create a project and navigate to Settings > Keys.

3. Click Add New Key and paste the WebSocket URL, API Key, and Secret into Configurations.

3. Gmail SMTP Password (Optional)

1. Go to your Google Account Security.

2. Ensure 2-Step Verification is enabled, then generate an App Password for "Zenith".

3. Copy the 16-character code into the Google App Password field.
