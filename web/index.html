Support & Help

Frequently Asked Questions

Everything you need to know about setting up, running, and securing your sovereign Zenith desktop agent.

Do I need to pay for API keys or monthly subscriptions?
No. Zenith utilizes Google Gemini Multimodal Live and LiveKit Cloud through their generous 100% free developer tiers. No credit card or monthly plan is required to get started with full real-time voice and vision capabilities.
Does any voice, screen, or memory data get stored in the cloud?
Never. All user facts, semantic memory matrices, and automation routines are stored exclusively inside a local SQLite database (zenith_memory.db) residing directly on your local SSD. No personal thoughts or activity logs ever leave your machine.
What are the system and hardware requirements?
Zenith is engineered natively for 64-bit Windows 10 and Windows 11. It requires a working microphone for duplex speech and an active internet connection for the LiveKit WebRTC audio transport. Because neural reasoning runs via Google's high-speed cloud edge, you do not need an expensive local GPU.
What should I do if Zenith cannot click or automate an application?
Some Windows utilities (such as Task Manager, Command Prompt as Admin, or software installers) run with elevated security permissions. Run Zenith as Administrator (right-click > Run as administrator) so that the Windows UI Automation (UIA) driver can interact with elevated desktop windows without restrictions.
Where can I report a bug or request technical support?
Encountered an issue or have a feature suggestion? File an issue in our Issue Tracker or start a thread on GitHub Discussions. Developer feedback is reviewed daily.
