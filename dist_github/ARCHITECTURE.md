## Overview
**Zenith** is a multimodal AI desktop assistant for Windows. It couples Google's Multimodal Live API with LiveKit's real-time streaming engine for bidirectional voice communication, supplemented by native Windows UI automation (`pywinauto`), autonomous browser control (`browser-use` / Playwright), an Apple-style Dynamic Island overlay UI (Electron + HTML/CSS), a desktop control center dashboard, and persistent SQLite + Mem0 memory.

## Components

### 1. Core Agent Engine (`agent.py`)
- **Purpose:** Entry point for the background AI daemon. Establishes the LiveKit session, initializes the Gemini Realtime multimodal connection, registers all agent tools, and pipes speech/state events to the UI.
- **Dependencies:** `livekit.agents`, `livekit.plugins.google`, `livekit.plugins.noise_cancellation`, `prompts.py`, `zenith_memory.py`, `agent_tools.*`.
- **Dependents:** Spawned as a child process by `electron_dashboard/main.js` or run standalone via `python agent.py console`.

### 2. Windows UI Automation Engine (`uia_control.py`)
- **Purpose:** Headless, text-based Windows UI automation using `pywinauto` with UIA backend. Parses window element hierarchies into structured JSON commands for `gemini-2.5-flash` to click, type, and navigate without screenshots.
- **Dependencies:** `pywinauto`, `pyautogui`, `google.genai`.
- **Dependents:** Imported by `agent_tools/os_control.py` and called by the agent during desktop automation tasks.

### 3. Visual Screen Control & Set-of-Marks (`computer_use.py`, `agent_tools/som_grounding.py`)
- **Purpose:** Vision-based computer control empowered by Set-of-Marks (SoM) visual grounding. Automatically identifies interactive UI boundaries, draws high-contrast numbered badges (`[1]`, `[2]`, `[N]`), and resolves actions with zero coordinate guessing and automatic proximity snapping.
- **Dependencies:** `pyautogui`, `google.genai`, `PIL`, `opencv-python-headless`.
- **Dependents:** Used directly by `agent_tools/os_control.py` for precision desktop automation.

### 4. Native Screen Stream Receiver (`agent_tools/screen_stream.py`)
- **Purpose:** High-speed native desktop screen receiver that hooks Electron's DesktopCapturer directly into LiveKit Agents / Gemini Live as an `rtc.VideoFrame` stream with sub-10ms latency.
- **Dependencies:** `livekit.agents`, `livekit.rtc`, `aiohttp`, `PIL`.
- **Dependents:** Linked into `agent.py` on startup.

### 5. Background Worker Swarm Manager (`agent_tools/task_manager.py`)
- **Purpose:** Asynchronous worker registry and lifecycle manager. Dispatches intensive operations (web browsing, research dossier compilation, computer use, disk ops) into parallel background tasks. Keeps the Gemini real-time voice channel open and responsive (<1.5ms dispatch overhead) and proactively vocalizes completion announcements via `session.say`.
- **Dependencies:** `asyncio`, `livekit.agents`, `ui_state`.
- **Dependents:** Used by `agent.py`, `agent_tools/web.py`, `agent_tools/research.py`.

### 6. Proactive Ambient Watchers (`agent_tools/ambient_watchers.py`)
- **Purpose:** Background ambient intelligence engine. Monitors Windows clipboard changes via zero-overhead sequence counter (`GetClipboardSequenceNumber`), classifies compiler errors across Python/Node/Rust/Java/Git, tracks compilation/build process termination via `psutil`, monitors battery/hardware constraints, and triggers non-intrusive proactive vocal and Dynamic Island alerts.
- **Dependencies:** `ctypes` (Win32), `psutil`, `re`, `ui_state`.
- **Dependents:** Linked into `agent.py` on startup.

### 7. Persistent PowerShell & Self-Healing Action Loops (`agent_tools/persistent_shell.py`)
- **Purpose:** Stateful interactive PowerShell session engine. Preserves working directory (`$PWD`), active Python/Node virtual environments, and environment variables across multi-turn interactions with sub-5ms command execution overhead. Features automatic cross-platform pre-healing (POSIX `export`, `source`, `rm -rf`, `touch`, `which`), execution policy automatic bypass, Windows binary compatibility mapping (`python3`/`pip3` -> `python`/`pip`), and post-execution filesystem state verification.
- **Dependencies:** `subprocess`, `asyncio`, `difflib`, `re`, `ui_state`.
- **Dependents:** Linked into `agent_tools/system.py` and `agent.py`.

### 8. Semantic Graph Memory & Vector RAG (`agent_tools/semantic_memory.py`, `zenith_memory.py`)
- **Purpose:** Hybrid Semantic Graph Memory engine. Employs dual-engine vector embeddings (`gemini-embedding-001` at 3072-dim with local subword n-gram vectorizer fallback at 256-dim), fast NumPy vector dot-product cosine similarity over SQLite BLOB storage, and a native Knowledge Graph engine (entities, directed typed relations, 1-hop and 2-hop subgraph traversal). Ranks context using Reciprocal Rank Fusion (RRF) across vector semantic similarity, lexical token overlap, and knowledge graph proximity.
- **Dependencies:** `numpy`, `sqlite3`, `google.genai`.
- **Dependents:** Linked into `agent.py` and `zenith_memory.py`.

### 9. Autonomous Web Agent (`agent_tools/web.py`)
- **Purpose:** Web search (DuckDuckGo), email dispatch via Gmail SMTP, Chrome DevTools Protocol (CDP port 9222) browser manipulation, and autonomous web browsing via `browser-use`.
- **Dependencies:** `browser-use`, `playwright`, `requests`, `ddgs`.
- **Dependents:** `agent.py`, `tests/test_browser_agent.py`.

### 10. Dynamic Island & Electron Shell (`electron_dashboard/`, `jarvis_ui.html`)
- **Purpose:** Desktop GUI providing an Apple Intelligence-style translucent top pill overlay, music widget, weather forecasts, and a glassmorphic dashboard for configuration and daemon lifecycle control.
- **Dependencies:** Electron, `electron-builder`, `electron-updater`, UDP socket on port `49152`.

### 15. Universal Emergency Motor Killswitch (`agent_tools/emergency.py`)
- **Purpose:** Atomic, zero-latency emergency killswitch for all motor, automation, visual, web, shell, and background audio systems. Immediately cancels active `computer_use`, `uia_control`, `browser-use`, PowerShell processes, and releases stuck hardware mouse/key locks in < 5ms.
- **Dependencies:** `asyncio`, `pyautogui`, `ui_state`.
- **Dependents:** Linked into `agent.py`.

Automatically archives superseded beliefs and preserves provenance in `zenith_memory_evolution_log`.
- **Dependencies:** `sqlite3`, `google.genai`, `re`.
- **Dependents:** Linked into `agent.py` and `agent_tools/dream_cycle.py`.

- **Purpose:** 5-point automated health inspection across database integrity (`PRAGMA integrity_check`), neural cloud inference latency (ms), persistent PowerShell engine response, hardware resource load (`psutil`), and background cognitive loops.
- **Dependencies:** `psutil`, `sqlite3`, `google.genai`, `ui_state`.
- **Dependents:** Linked into `agent.py`.

## Data Flow

1. **User Voice Input:** User speaks -> LiveKit WebRTC audio stream -> Noise Cancellation (BVC) -> Gemini Multimodal Live API.
2. **State Updates:** Voice state change (`listening`, `thinking`, `speaking`) -> `update_ui()` -> UDP packet to `127.0.0.1:49152` -> Electron main process receives UDP -> broadcasts IPC to `jarvis_ui.html` -> UI morphs smoothly.
3. **Tool Execution:** Gemini triggers tool call -> `agent.py` routes to `agent_tools` / `uia_control` -> tool executes locally -> result returned to Gemini -> speech response streamed back to user.
4. **Memory Lifecycle:** When session goes idle or terminates -> watchdog triggers `extract_and_learn_facts()` -> conversation turns analyzed by Gemini -> facts upserted into `zenith_memory.db`.

## Conventions
